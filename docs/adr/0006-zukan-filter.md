# ADR-0006: 図鑑の位置ピル（フィルター）と記録一覧

日付: 2026-10-29 / 状態: 採用

## 文脈

付録A A-5 は上部帯の左を「位置ピル(フィルター)」とだけ書き、どの状態を巡るかは書いていない。A-8 は「図鑑カード→その魚の記録一覧」とあるが一覧の見た目は未指定。

## 決定

- ピルは「登録済み釣り場の名前」を順に巡るフィルター。初期値は現在地に最も近い釣り場（Home と同じ）。記録に「現在地」（未登録の場所で保存したもの）があれば、それも巡回に含める。仕様外の語（「すべて」など）は足さない。
- カウント「7 / 12」とリングは、フィルター後に釣れている魚種数 / 付録B の魚種数（12）。
- 最大記録（フィルター後の最大サイズ）の魚種だけ数字とバッジを橙。並びは「釣った魚種（付録B の順）→ 未釣果（付録B の順）」。
- 記録一覧は中サイズのシート（bg #121214）。行は h56、サムネ 40 r8、日時 13/500、場所 12/500 補助、右にサイズ 16/500＋cm。寸法はすべて既存トークンから。

## 結果

- 見た目は付録A のまま。フィルターの意味だけここで固定した。
