# ADR-0013: 釣れ率 v2 の定式化、警報の表示、設定画面

日付: 2026-10-29 / 状態: 採用

## 文脈

指示書 §4: 「v2（M6）は自分の釣果ログで係数を再学習（Create ML Tabular を端末内で実行）」。§3-1: 気象警報を表示。L15: 設定画面（注意書き・データ削除）。付録A に設定画面・警報の見た目は無い。

## 決定

### v2
- 釣果の記録に v1 の要素点数（6個）を保存する。学習データは「釣果時の要素（0...1）＝正例」と「一様乱数＝負例（正例の3倍）」。負例を乱数にするのは、釣れなかった時刻の記録が無いため（釣果ログだけからの再重み付け）。
- Create ML Tabular の `MLLogisticRegressionClassifier` で学習し、単位ベクトルの予測確率の logit 差から係数 β を復元。係数 → 配点 w_i = 100·m_i·exp(β_i)/Σ m_j·exp(β_j)（m = v1 の配点、exp(β) は 0.5〜2 にクランプ）。β=0 なら v1 と一致。
- Create ML が使えない環境（コンパイルできない／学習に失敗）では TideCore の自前ロジスティック回帰（同じ定式化、Linux でテスト済み）。
- 10 件未満なら v1。内訳は v2 でも 6 要素のまま（説明可能性 §3-4）。

### 警報
- WeatherKit の alerts の summary を Home の上部帯の下に橙のピル（日付チップと同じ寸法）で出す。色は付録A の橙。

### 設定画面
- Home の round36(dots) からシート。項目: 釣れ率（配点と学習日時、学び直し）、学習用の書き出し（ZIP、ShareLink）、データ削除（確認ダイアログ）、注意書き、バージョン。寸法は既存トークンから。

## 結果

- 仕様外の色は増えていない。文字ラベルは安全と操作に必要な最小限。
