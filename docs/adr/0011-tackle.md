# ADR-0011: Tackle 画面の操作と在庫メーターの意味

日付: 2026-10-29 / 状態: 採用

## 文脈

付録A A-6 は寸法と初期値を決めているが、在庫行のメーター（30/55/90/65/20%）が何を表すか、右上の＋と円・フックのタップの意味は書いていない。A-7 の −/+ は「アプリを開かず在庫更新」とある。

## 決定

- 在庫行のメーター = そのシンカーの使用回数 ÷ 最多の使用回数（L14 の「使用頻度」）。使用回数は Catch の保存時に増える。
- 円（シンカー）とフックのタップ = 「選択中」にする。選択中は Catch のタックルピルの初期値。
- 在庫行の数字はタップで +1、長押しで −1。フックはステッパー。右上の＋は選択中のシンカーとフックを +1。左上の ‹ は Home へ。
- ウィジェットの −/+ は `AdjustStockIntent`（AppIntents）が共有 SwiftData を直接更新し、スナップショットの在庫も書き換える。アプリ側は Tackle 画面の変更のたびにスナップショットを更新する。
- 在庫は 0 未満にならない。

## 結果

- 在庫と選択はアプリ・ウィジェットで常に同じ SwiftData の値を指す。
