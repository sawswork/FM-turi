# ADR-0003: 初期データと退避値

日付: 2026-10-29 / 状態: 採用

## 文脈

- 付録A は「城ヶ島 西側」など三浦半島の釣り場を例として画面に出している。登録済み釣り場が0件だと Home の位置ピルに出す名前がなく、L3〜L8 の画面が仕様の見え方にならない。
- WeatherKit の Capability は L16 までオーナーが有効化できない。それまで実機では WeatherKit が失敗する。
- 位置情報は拒否されることがあり、シミュレータでは測位が無いことが多い。

## 決定

1. 初回起動時に付録A A-4 の登録済み4点（城ヶ島 西側／三崎港 北堤／荒崎／剱崎）を SwiftData に投入する（`SeedData`）。座標は実在の地名の概略位置。L9 でユーザーが削除・追加できる。
2. 測位前・拒否時・シミュレータでは既定点を城ヶ島（35.1352, 139.6079）にする（`LocationService.fallbackPoint`）。
3. 気象の取得に失敗したら「同一地点の最新キャッシュ → 固定値モック」の順に退避し、`source` 列に由来（weatherkit / open-meteo / mock）を残す。Detail（L5）で取得時刻と由来を出す。
4. 位置ピルは「現在地に最も近い登録済み釣り場」の名前を出し、登録が無ければ仕様にある語「現在地」を出す。

## 結果

- 仕様外の文字ラベルは増えない（すべて付録A にある語）。
- 実機でも L16 以前に画面が埋まる。モック由来のときはその旨が Detail で判別できる。
