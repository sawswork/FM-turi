# ADR-0005: 釣れ率 v1 の係数と、Home/Detail の表示規則

日付: 2026-10-29 / 状態: 採用

## 文脈

指示書 §4 は配点（潮25・マズメ20・風15・気圧15・水温15・波10）と「内訳を必ず出す」ことだけを決めている。各要素を点数に落とす係数、4条件メーターの割合と色の意味、Detail の月相7つの並び、取得時刻の出し方は決まっていない。

## 決定

### 係数（`TideCore.FishingScore`、すべて定数で変更可能。v2（L15）で再学習）
| 要素 | 入力 | 点数 |
|---|---|---|
| 潮の動き 0-25 | 潮位の変化率 cm/h（30分先との差×2） | 30 cm/h 以上で満点、比例 |
| マズメ距離 0-20 | 日出・日没の近い方までの分 | 0分で満点、180分以上で0、比例 |
| 風 0-15 | 風速 m/s | 0 で満点、10 m/s 以上で0、比例 |
| 気圧変化 0-15 | 3時間の変化 hPa | -3 以下で満点、0 で半分、+3 以上で0 |
| 水温適性 0-15 | 海水温と対象魚種の適温帯 | 中心15・端7（付録B）、帯外は端から4°C で0 |
| 波 0-10 | 波高 m | 0 で満点、2 m 以上で0、比例 |

- 入力が無い要素は 0 点にし `missing` を立てる（内訳で見分けられる）。
- 対象魚種は当面カサゴ（通年）。L15 で釣果ログの最多魚種に切り替える。
- Detail の内訳バーは「25 点満点に対する割合」（付録A の例 +22→88%、+16→64% に一致）。50% 以上を橙、未満を白。行は点数の高い順。
- 24時間バーは選択中の日の毎正時の釣れ率。気象は当日の値で一定、海況は時系列の最寄り値。

### 4条件メーター（Home）
| 条件 | 割合 | 色 |
|---|---|---|
| wind | 風速/10 | 50% 以上=橙（注意）、未満=白 |
| wave | 波高/2 | 50% 以上=橙、未満=白 |
| drop（水温） | 水温適性の点数/15 | 50% 以上=緑（好条件）、未満=白 |
| pressure | 3h変化の絶対値/6 | 下降=緑、他=白 |

wind のアイコンは「風が吹いていく向き」（風向+180°）に回転する。既定（データ無し）は仕様の 40°。

### Detail
- TIDE のトレンドは「↑/↓＋潮回り」。上げ潮を緑。PRESS は「↓3」の形で、下降を緑。WIND のトレンドは16方位を橙。
- 月相7つ: 今日より前の節目（新月0・三日月3.7・上弦7.4・満月14.8・下弦22.1 のうち最大3つ）→ 今日 → 明日 → 今日より後の節目。今日=不透明度1＋橙枠。
- 指示書 §4 の「取得時刻を Detail に出す」ため、内訳の最後に `DATA M/d HH:mm` と由来（weatherkit / open-meteo / tide736 / mock）を同じ書式で1行足した。仕様外の語はラベル `DATA` のみ。

## 結果

- 係数は 1 箇所に集約され、v2 で差し替えられる。
- 色・寸法は付録A のまま。意味づけだけをここで固定した。
