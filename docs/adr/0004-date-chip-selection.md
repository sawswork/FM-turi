# ADR-0004: 日付チップの橙は「選択中の日」

日付: 2026-10-29 / 状態: 採用

## 文脈

付録A A-1 4 は「今日=bg橙文字黒、他=bg #1C1C1E 文字 #8E8E93」とし、操作として「日付チップで切替」「グラフ横スクロール」を挙げている。切替後にどのチップが橙になるかは書かれていない。

## 決定

- チップの橙は「選択中の日」を表す。初期選択は今日なので、起動時の見え方は仕様どおり（今日が橙）。
- チップのタップとグラフの横スクロールは同じ選択状態を共有する（どちらを操作しても一致する）。
- 潮位曲線の不透明度（今日=1、他=0.35）とマズメ帯の濃さも「選択中の日」に追従する。
- 現在線・現在点・時刻ラベルは実際の今日にだけ描く。

## 結果

- 色・数値は仕様のまま。意味だけ「今日」→「選択中（既定=今日）」に広げた。
