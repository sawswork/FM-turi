# ADR-0009: 潮汐の端末内計算（調和定数の出どころと近似）

日付: 2026-10-29 / 状態: 採用

## 文脈

指示書 §4: 「M3 で調和定数ベースの端末内計算へ置換（主要分潮 M2,S2,K1,O1,N2,K2,P1,Q1 以上）」。各港の調和定数の表は同梱していない（公開表を取得する手段が開発環境に無い）。

## 決定

1. 調和定数は、その港の tide736 予測値（20分刻み、30日分）を最小二乗で当てはめて得る。自由に当てるのは M2, S2, N2, K1, O1, Q1。30日では分離できない K2 は S2 の 0.2723 倍（同位相）、P1 は K1 の 0.3309 倍（同位相）として設計行列に組み込む（標準的な推定比）。合計 8 分潮。
2. 節点補正（f, u）は省略する。誤差は振幅で数%程度で、釣れ率の用途では許容する。
3. 当てはめは最初に tide736 を取得した後にバックグラウンドで1回行い、残差 RMS が 6cm 以下のときだけ採用して SwiftData に保存する。採用後はその港の潮汐を通信なしで計算し、Detail の DATA に `harmonic` と出す。
4. 日出没は SunCalc、月齢・潮回りは MoonCalc（tide736 の値は使わない）。
5. シミュレータ・CI は従来どおり正弦波モック。

## 結果

- 2回目以降の起動では潮汐の通信が不要になり、オフラインでも3日分が出る。
- 調和定数の精度は tide736 の予測精度に依存する（tide736 は海上保安庁・気象庁の定数に基づく）。
