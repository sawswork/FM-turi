# ADR-0008: 釣り場候補の検索と登録の挙動

日付: 2026-10-29 / 状態: 採用

## 文脈

付録A A-4 は見た目（候補点・ポップアップ・バッジ・リスト）を決め、「候補点は MKLocalSearch 結果、登録済みは SwiftData」「実機では MapKit の地図に差し替え」とする。検索の範囲・頻度、右上＋の意味、地図の配色は未指定。

## 決定

- 検索: 現在地を中心に 0.2° の領域で「漁港」「堤防」「岬」「磯」「港」を MKLocalSearch（POI のみ）。加えて同梱の tide736 港一覧から 15km 以内を候補にする。名前が同じで 500m 以内なら重複としない。
- 再検索の抑止: 5km 以内で 7 日以内に検索済みなら再検索しない（候補は SwiftData に `searchedAt` 付きで保存）。
- 右上の＋: 候補を選択中ならそれを登録、未選択なら現在地を逆ジオコーディング（CLGeocoder、Apple のサービス）した地名で登録。地名が取れなければ「現在地」。
- 登録済みの色: 最寄り（Home の位置ピルと同じ釣り場）=橙、釣れ率 60 以上=白、他=補助色。候補のポップアップの釣れ率は選択時にその地点の条件で計算する。
- 地図: MapKit 標準（ダーク、POI 非表示、操作ボタン非表示）。仕様の陸 #0E0E10 の塗りは MapKit では再現できないため標準配色に委ねる。
- 釣り禁止の判定はしない旨の注意書きは L10 の注意書き画面にまとめる。

## 結果

- 候補点が無限に増えないよう再検索を抑止し、通信は MapKit と tide736 同梱データだけ。
