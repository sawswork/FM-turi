# ADR-0010: ウィジェットのデータ経路

日付: 2026-10-29 / 状態: 採用

## 文脈

ウィジェットは位置情報もネットワークも持たず、表示時間も短い。SwiftData の共有ストアを拡張から直接開くこともできるが、起動コストと Swift 6 の分離の扱いが重い。

## 決定

- アプリ（Home）が条件と潮汐を読み込んだ直後に `WidgetSnapshot`（釣り場名・釣れ率・毎正時の釣れ率24個・4条件メーター・月齢・潮回り・上げ下げ・潮位24個・在庫）を App Group の UserDefaults に JSON で書き、`WidgetCenter.reloadAllTimelines()` を呼ぶ。
- ウィジェットはそれだけを読み、毎正時のエントリで時間ごとの釣れ率に切り替える。未取得時は付録A の例（placeholder）。
- 在庫の −/+（L12）は AppIntent が共有 SwiftData を直接更新し、スナップショットの在庫も書き換える。
- 角丸はシステム既定（付録A の r28 は WidgetKit では指定できない）。`contentMarginsDisabled()` で余白は付録A の数値を使う。

## 結果

- ウィジェットの表示はアプリを最後に開いた時点の条件に基づく（最大で次にアプリを開くまで古くなる）。
