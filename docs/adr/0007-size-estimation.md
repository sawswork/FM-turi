# ADR-0007: サイズ推定の方法

日付: 2026-10-29 / 状態: 採用

## 文脈

指示書 §4: 「Vision で基準物（メジャー・500円硬貨）を検出して換算。LiDAR機は ARKit の距離で補助。推定できなければ数字を空にしてユーザー入力」。Vision には硬貨やメジャー専用の検出器が無い。

## 決定

1. 魚の画像上の長さ = `VNGenerateObjectnessBasedSaliencyImageRequest` の最大の顕著領域の長辺。
2. 基準物 = `VNDetectRectanglesRequest` で見つかる「魚の面積の 20% 未満」「縦横比 1.35 未満」の矩形を 500円硬貨（直径 26.5mm）とみなす。メジャーの目盛り読み取りは行わない（精度が出ないため）。メジャーは写真に写っていればユーザーが読んで入力する。
3. 換算結果が 3〜200cm の範囲外なら推定失敗として空にする。
4. 推定値はサイズピルに入れるだけで、ユーザーが上書きできる。記録には出どころ（coin / lidar / 手入力）を残す。
5. LiDAR: ARKit の距離と焦点距離から 1px の実寸を出す式を `TideCore.SizeEstimate.lidarReference` に用意。ARKit セッションを Catch 画面に組み込むのは、写真ライブラリからの選択が主経路のため今回は見送り（PROPOSALS に記載）。

## 結果

- 硬貨が写っていれば自動で入り、写っていなければ空（仕様どおり）。
